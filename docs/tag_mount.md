# 标定板：双色打印与插座一体安装

生成文件：

- `assets/print/tag_mount_black_white_H2C.3mf`：双色打印版，白板 + 黑白码块，两个 part 已分到 1/2 号挤出机；
- `assets/print/tag_mount_plate.stl`：单色版，凹框留给纸标（码面 z=3）；
- `assets/print/tag_aruco_6x6_250_id0.png`：ArUco 6×6_250，ID 0；
- `assets/print/tag_mount_spec.json`：尺寸、孔位、基准和名义坐标；
- `assets/print/tag_mount_layout.svg`：布局图。

重新生成：

```powershell
python scripts/pipeline/create_tag_mount.py
```

## 打印（双色）

- 0.2 mm 层高、0.4 喷嘴、PLA、30% 填充；
- 白色 → 1 号挤出机，黑色 → 2 号挤出机；
- **背面朝下平放**，不需要支撑：旧的 6 mm 卡脚和 4 条凸台已经删除，背面是纯平面；
- 码块和凸框顶面都在 z=4，打印后是一个齐平平面。

单色备选：打 STL，另打一张 45.8–46.0 mm 的纸标贴进凹框。凹框开口是 **46×46**，不是 50×50。

## 和插座装成一体

支架通过两个耳朵直接拧在插座法兰上，拧紧后板与插座是刚性整体：

- 板背面贴插座法兰正面，也就是 target 的 `z=0` 平面；
- 板左边贴 `x=+45`（法兰右边缘），下边贴 `y=-45`（法兰下边缘）；
- 两个 Ø6.6 孔对准法兰上现成的 Ø6.9 通孔；
- 用 2 颗 M6×16 螺栓从正面穿入，法兰背面加垫片和螺母拧紧。

孔位对照：

| 支架局部坐标 | target 坐标 | 插座孔 |
| --- | --- | --- |
| (-9.06, 8.95) | (35.94, -36.05) | Ø6.89 通孔 |
| (-9.06, 80.95) | (35.94, 35.95) | Ø6.89 通孔 |

耳朵内角到法兰中心 Ø71.5 孔边缘还有 ≥2.5 mm 间隙，不会碰中间的圆柱凸台。

## 尺寸（模型给定）

- 板 80×70×3，含耳朵总尺寸 96×90；
- 码 46.0 mm = 8 × 5.75 mm，码面 z=4（与凸框齐平）；
- 码中心（支架局部 (40, 35, 4)）→ target `(85, -10, 4)` mm；
- 码上边朝 target `+y`；打印图案相对 PNG 上下镜像，从正面看与 PNG 完全一致（已用脚本核对）。

## 装完必须做的

1. 用卡尺量实际码心偏移，把实测 `T_target_tag` 记进实验记录；名义 `(85, -10, 4) mm` 只作参考。
2. 检查拧紧后板不晃、耳朵与法兰贴合。
3. 用 ArUco 检测 + PnP 看重投影误差和静止重复性（同一位置多帧位姿标准差）。
4. 不要只抄名义矩阵就宣称拿到 6D 真值；精度还取决于相机标定、打印平面度和装配刚性。
